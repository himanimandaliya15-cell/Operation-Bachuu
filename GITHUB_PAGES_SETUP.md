# GitHub Pages deployment

1. Upload/push the contents of this folder to the repository branch you want to publish.
2. In GitHub: **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your branch (usually `main`) and folder `/ (root)`.
5. Save and wait for the Pages deployment to finish.
6. Open the generated `github.io` URL in Chrome.

The project includes `chrome-compat.js` to prevent optional audio/autoplay failures from stopping the page.
